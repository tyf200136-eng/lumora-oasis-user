# واحة لومورا — نسخة المستخدم (User)

## خطوات التشغيل
1. فك الضغط عن الملف
2. افتح الفولدر بـ VSCode
3. Terminal > New Terminal
4. مرة وحدة بس:
   ```
   npm install
   ```
5. كل مرة تبي تشغل المشروع:
   ```
   npm run dev
   ```
6. بيطلع رابط زي `http://localhost:5173/` — افتحه بالمتصفح

## الصفحات
- `index.html` — عرض الخريطة والجزيرة 3D
- `ad-detail.html` — تفاصيل إعلان (بعد الضغط على لوحة بالجزيرة)

## ملاحظات
- الجزيرة 3D حاليًا Placeholder مؤقت داخل `public/island.js`
- `npm run build` يبني نسخة إنتاجية داخل فولدر `dist`
